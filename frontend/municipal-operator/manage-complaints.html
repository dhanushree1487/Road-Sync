Operator Assessment Factors (1 to 3 Scale)

Each factor requires an integer value from 1 to 3. All 4 factors must be validated to calculate authoritative priority via Java DefaultPriorityPolicy.

1. Damage Severity Weight ×3 (30%)

Physical road defect scale (confirmed from report / field inspection).

2. Accident Risk Weight ×3 (30%)

Immediate safety hazard to two-wheelers, buses, and motorists.

3. Traffic Corridor Rank Weight ×2 (20%)

Manual municipal assessment based on corridor volume tier (not live sensor telemetry).

4. Road Importance Weight ×2 (20%)

Administrative road classification in Tamil Nadu transport hierarchy.
